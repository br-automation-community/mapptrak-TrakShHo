O	V6.00.0:

	General Information:
	
	- Version is only compatible with mapp Motion SW version greater or equal V6.8.0
	- Cycle time must be between 0.8 and 2ms
	- Velocity limit for handover is 4m/s. Correct functionality with higher velocity cannot be guaranteed
	- Distribution with MIT license file
	- This version introduces the Catch-based handover, eliminating the need for a dual track area
	
	Interface changes:
	
	- TSH-I#0020: New ProcessPoints structure: ProcessPoint_GetData and ProcessPoint_DeleteShuttle are now required on the sending side
	- TSH-I#0021: New parameter "CatchPosition" in the parameter structure of TSH_AsmReceiveShuttleAdd to define where shuttles are caught
	- TSH-I#0022: Updated POWERLINK communication data size constants
	
	New Functionality:
	
	- TSH-I#0020: Handover is now performed using the Catch functionality of mapp Motion, enabling shuttle transfer without a physical dual track area
	- TSH-I#0021: Shuttles are automatically "caught" at the CatchPosition when entering the overlapping segment area
	- TSH-I#0022: The function block MC_BR_SecAddShuttle_AcpTrak runs continuously in catch mode to detect incoming shuttles
	
	Internal Changes:
	
	- Updated POWERLINK communication buffer sizes
	- Removed support for handover mode "Standstill with direction change" (tshHANDOVER_STANDSTILL_CHANGE_DIR)
	- Simplified handover process by utilizing mapp Motion catch functionality
